# 🤖 Local AI Chat using Ollama & Streamlit

## 📌 Project Overview

Local AI Chat is a Generative AI application built using Python, Streamlit, and Ollama. It uses the Llama 3.2 Large Language Model (LLM) to generate AI responses based on user-provided questions.

The application runs locally and allows users to interact with an AI model without depending on a hosted chatbot interface.

## 🛠️ Technologies Used

- Python
- Streamlit
- Ollama
- Llama 3.2
- Large Language Models (LLMs)
- Generative AI

## ✨ Key Features

- Interactive chatbot interface.
- Local AI model integration.
- Real-time response generation.
- User-friendly Streamlit interface.
- Local LLM execution using Ollama.

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/Vinay1213143/Local-AI-Chat-Ollama-Streamlit.git
```

### 2. Navigate to Project Folder

```bash
cd Local-AI-Chat-Ollama-Streamlit
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Install Ollama

Download Ollama from:

https://ollama.com/

### 5. Download Llama 3.2 Model

```bash
ollama pull llama3.2
```

### 6. Run the Application

```bash
streamlit run app.py
```

Open the local URL displayed in your terminal.

## 🔄 Project Workflow

1. User enters a question in the Streamlit interface.
2. Streamlit captures the user input.
3. Ollama sends the prompt to the locally running Llama 3.2 model.
4. The LLM processes the question.
5. The generated response is displayed on the Streamlit application.
